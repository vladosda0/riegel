# Аватар ассистента

Портрет Шурика — ИИ-помощника по стройке. Один и тот же образ используется в
двух каналах, чтобы это был «тот же самый помощник»:

| Где | Как подключено |
| --- | --- |
| Веб-сайдбар | `ASSISTANT_AVATAR_SRC` в `src/data/assistant-identity.ts` → компонент `AssistantAvatar` |
| Telegram-бот | вручную через BotFather `/setuserpic` (см. vladosda0/rovno-bots#3) |

| Файл | Назначение |
| --- | --- |
| `shurik.png` | Портрет-аватар, квадрат, минимум 512×512 |

### Требования к файлу

- **PNG, квадрат, ≥ 512×512.** BotFather не принимает картинку меньше 512 по
  стороне, а сайдбар рендерит её вплоть до 48 CSS-пикселей на retina.
- **Прозрачный фон предпочтителен.** `AssistantAvatar` обрезает изображение в
  круг через `rounded-full` + `object-cover`, поэтому важное содержимое должно
  помещаться в центральный круг, а не в углы.
- **Без текста на картинке.** На 20×20 в строке чата он всё равно нечитаем.

### Если файла нет

`AssistantAvatar` перехватывает ошибку загрузки и откатывается на прежнюю
иконку `<Bot>` из lucide. Это не декоративная защита: картинку кладёт человек,
её не производит сборка, поэтому свежий клон не должен показывать «битую
картинку» в каждой строке чата.
