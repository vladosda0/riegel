# Аватар ассистента

Портрет Шурика — ИИ-помощника по стройке. Один и тот же образ используется в
двух каналах, чтобы это был «тот же самый помощник»:

| Где | Как подключено |
| --- | --- |
| Веб-сайдбар | `ASSISTANT_AVATAR_SRC` в `src/data/assistant-identity.ts` → компонент `AssistantAvatar` |
| Telegram-бот | вручную через BotFather `/setuserpic` (см. vladosda0/rovno-bots#3) |

| Файл | Назначение |
| --- | --- |
| `shurik.png` | Портрет-аватар, 512×512, PNG8 с прозрачностью, 26 КБ |

### Требования к файлу

- **PNG, квадрат, ≥ 512×512.** BotFather не принимает картинку меньше 512 по
  стороне, а сайдбар рендерит её вплоть до 48 CSS-пикселей на retina.
- **Прозрачный фон.** `AssistantAvatar` обрезает изображение в круг через
  `rounded-full` + `object-cover`, и Telegram делает ровно то же самое с фото
  профиля. Поэтому фигура вписана целиком во **вписанную окружность**, а не в
  квадрат: иначе круг срезает углы, а в правом верхнем углу у Шурика лампочка.
  Исходник 372×405 подобран по масштабу и вертикальному сдвигу так, что за
  границу круга не выходит ни одного непрозрачного пикселя.
- **Без текста на картинке.** На 20×20 в строке чата он всё равно нечитаем.
- **Бюджет по весу — как у иконок приложения.** `android-chrome-512x512.png`
  того же размера весит 16 КБ; портрет ужат квантованием палитры до 256 цветов
  (26 КБ против 203 КБ у RGBA-мастера), разница на 96 px и меньше не видна.
  Полутоновые точки и сглаживание контура при этом сохранены.

### Если файла нет

`AssistantAvatar` перехватывает ошибку загрузки и откатывается на прежнюю
иконку `<Bot>` из lucide. Это не декоративная защита: картинку кладёт человек,
её не производит сборка, поэтому свежий клон не должен показывать «битую
картинку» в каждой строке чата.
